# Game Test

Boilerplate game HTML5/JS đơn giản: người chơi điều khiển ô vuông màu xanh để hứng các ô rơi xuống, mỗi lần hứng được +10 điểm.

## Chạy thử

Mở trực tiếp file `index.html` bằng trình duyệt, hoặc chạy một server tĩnh:

```bash
npx serve .
```

## Điều khiển

- Mũi tên hoặc WASD để di chuyển
- Hứng các ô màu vàng để ghi điểm

## Cấu trúc

- `index.html` — khung giao diện và canvas
- `style.css` — giao diện
- `script.js` — logic game (game loop, điều khiển, va chạm, tính điểm)
